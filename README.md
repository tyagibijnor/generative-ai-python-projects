This repository is intended to document my journey from Python programming to building practical Generative AI applications through experiments, tutorials, and projects.

- Explore Large Language Models (LLMs).
- Learn prompt engineering techniques.
- Experiment with AI APIs using Python.
- Understand embeddings and semantic search.
- Build Retrieval-Augmented Generation (RAG) applications.
- Explore AI Agents and workflow automation.

## ⚙️ Getting Started

### Prerequisites

- Python 3.10 or later
- pip
- Git
- API key for the model provider used by a particular project

### Clone the Repository

```bash
git clone https://github.com/tyagibijnor/generative-ai-python-projects.git

cd generative-ai-python-projects
```

### Project Setup

Each project will contain its own setup instructions and dependencies.

A typical Python project setup:

```bash
python -m venv .venv
```

Activate the environment:

```bash
# Linux / macOS
source .venv/bin/activate

# Windows
.venv\Scripts\activate
```

Install dependencies from the project's requirements file when available:

```bash
pip install -r requirements.txt
```

## 🔐 API Key Security

- Store API keys in environment variables.
- Use a `.env` file for local development where required.
- Never commit API keys, passwords, or other secrets.
- Keep `.env` in `.gitignore`.
